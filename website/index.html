Run it on your computer, with your own AI key

# install
$ git clone https://github.com/VishStack01/Propelo && cd Propelo
$ pip install -e .
# your model, your key (or put them in .env)
$ export PROPELO_LLM=anthropic # openai, gemini, ollama
$ export ANTHROPIC_API_KEY=sk-ant-...
$ propelo llm test
# go
$ propelo init && propelo serve # http://127.0.0.1:8765

Scanning, filtering and tracking need no AI. Reading your resume, scoring fit and writing call the model you pick, with your key, so only those requests leave your computer. With Ollama nothing leaves it, and it costs nothing.
